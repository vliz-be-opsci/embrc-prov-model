Explanation

Example provenance metadata file for Dataset 2, which consists of the outputs of the FlowCam: images 
and a file of species identifications created from the sample collected during the event described by 
Dataset 1, additionally a protocol document and a software settings file.
This metadata file describes the provenance of those and the activities and people involved in the work.
Dataset 2 has two versions: this one in text and another in JSON-LD. The same explanation applies 
to both (but cannot be added to the JSON-LD version without messing it up). 
See https://github.com/vliz-be-opsci/embrc-prov-model/tree/main/examples for more detail on the 
experiment that this dataset is created from.

The metadata fields here follow the classes and properties of the EMBRC conceptual model. 
See https://github.com/vliz-be-opsci/embrc-prov-model/tree/main/docs for more detail on this model. 
Note that in this example we may not have used every single property of every single class. 

This file is written in plain text, which could be something that an individual researcher would likely 
feel more comfortable with creating themselves for their own research data, especially if they do 
not have any data managers to help them out.

To make this file more compact and easier to read, we first list the metadata for objects  
that occurr more than once in this record, or which have to be described with more than one value. 
We will then refer to them by their name or identifier within the rest of the metadata.
