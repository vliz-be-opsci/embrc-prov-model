# Documentation

This folder provides materials to support the understanding of the model.

### Content

- **EMBRC provenance model PDF**: once we have finished our paper that lays out and explains the provenance model, it will be put here. Accompanying that paper are [example metadata records](https://github.com/vliz-be-opsci/embrc-prov-model/tree/main/examples) following the provenance model.
- **FAIR Data Management: Provenance and the Nagoya Protocol**: an explanation of the Nagoya Protocol, ABS permits, and how this all relates to provenance of biological material
- **Diagrams**: visualisations of the model (its classes and properties) that illustrate the structure and concepts can be found here: [EMBRC-prov-model-Activity.png](https://github.com/vliz-be-opsci/embrc-prov-model/blob/main/docs/EMBRC-prov-model-Activity.png), [EMBRC-prov-model-AgentLocation.png](https://github.com/vliz-be-opsci/embrc-prov-model/blob/main/docs/EMBRC-prov-model-AgentLocation.png), [EMBRC-prov-model-Entity.png](https://github.com/vliz-be-opsci/embrc-prov-model/blob/main/docs/EMBRC-prov-model-Entity.png)
